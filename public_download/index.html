Blynk Light

Điều khiển ESP32 Relay siêu tốc từ Quick Settings

Phiên bản: 1.0 • Dung lượng: 24 MB • Android 7.0 - 16
⬇️ TẢI FILE APK TRỰC TIẾP

Cách cài đặt trên điện thoại:

  1. Bấm nút Tải file APK trực tiếp ở trên.
  2. Mở file BlynkLight.apk vừa tải xuống trong thanh thông báo hoặc mục Tải về.
  3. Chọn Cài đặt (bật "Cho phép từ nguồn này" nếu hệ thống yêu cầu).
  4. Mở app, cấu hình Blynk Auth Token và thêm 2 ô Đèn 1 & Đèn 2 vào Control Center để sử dụng.
